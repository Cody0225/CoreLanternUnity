### Long (800-1000 字、メディア記事用)
```
『Eggcore Protocol』は、ヴァンパイア・サバイバーズや Brotato が
切り開いたサバイバー・ローグライトに、タワーディフェンスの
「守る」要素を融合した一人開発のインディーゲームです。

プレイヤーは「相棒キャラクター」となり、中央のコア「データエッグ」
を守りながら、押し寄せる敵を自動射撃で撃退します。10 Wave 構成の
1 ラン (約 15-20 分) の中で、データを集め、モジュールを取得し、
進化を重ねていきます。

11 種類の個性的な相棒キャラクター (Cobalt Pup、Halo Caster、
Solar Anchor 等) はそれぞれ専用シグネチャ機構を持ち、3 ルート
(SPEED / POWER / GUARD) × 4 段階の進化に加え、特定条件で 6 種類
のクロス進化 (Nova Aegis 等) へ発展します。

5 つの異なるステージ (Lantern Field / Lava Cache / Broken Core
Network / Frost Vault / Storm Spire) には、それぞれ専用敵と
専用ハザード (溶岩 / 凍結クリスタル / ランダム雷撃 等) が配置
されており、立ち回りの判断が問われます。

Wave 5 の中ボス Pulswyrm と Wave 10 のラスボス Nullwyrm はそれぞれ
HP 50% で形態変化し、Nullwyrm は「Spiral Corruption」「Glitch Summon」
「Core Mark」の 3 種類の専用攻撃を駆使する Phase 2 へ移行します。

60+ モジュール × 15+ レリックの組み合わせで、SPEED 機動型から
GUARD タンク型まで多様なビルド構築が可能。Brotato 流の Reroll /
Lock / Banish カード管理システムにより、運要素を最小化しています。

開発は Embercore Studio (個人開発)。Steam アーリーアクセス価格は
$2.99 と低価格に抑え、ジャンルファンが気軽に試せる設計です。
```

## ❓ FAQ FOR PRESS

### Q. このゲームの一番のセールスポイントは?
**A.** 「ヴァンパイア・サバイバーズと Brotato の良さを取り入れつつ、
タワーディフェンスの『守る』要素を加えた」 ハイブリッドジャンルです。
1 ラン 15-20 分の手軽さと、11 キャラ × 3 ルート × 6 クロス進化の
組み合わせの深さを両立しています。

### Q. ヴァンサバや Brotato との差別化は?
**A.** 「中央のコアを守る」というタワーディフェンス要素が最大の差別化。
プレイヤーは画面を自由に動けますが、コアから離れすぎると失格になる
仕組み。これにより「攻めるか守るか」の戦略判断が常に求められます。

### Q. なぜソロ開発を選んだか?
**A.** 「一人で作りたい」というインディー精神を実現するため。Unity の
強力なエコシステムにより、プログラミング・デザイン・アートディレ
クションの全工程を一人で完結できる時代になっています。

### Q. アーリーアクセスの期間は?
**A.** 6-12 ヶ月を予定。EA 期間中はユーザーフィードバックを最重視し、
キャラ追加 / ステージ追加 / 難易度追加を実装します。EA 価格 $2.99 は
維持し、フル版 1.0 で $4.99 に値上げ予定 (EA 購入者は追加課金不要)。

### Q. 配信・実況・収益化は OK?
**A.** すべて自由です。EA 期間中の配信・実況・収益化を含むあらゆる
コンテンツ作成を歓迎します。クレジット表記は任意 (「Embercore Studio
の Eggcore Protocol」と表記いただけると嬉しいです)。

### Q. 多言語対応は?
**A.** EA 時点では日本語のみ。フル版 1.0 までに英語対応を予定。
コミュニティ翻訳も歓迎します (将来検討)。

### Q. Mac / Linux / Switch / Mobile 対応は?
**A.** EA 時点では Windows のみ。Mac / Linux は Unity ビルドターゲット
追加で対応可能性あり (要望次第)。Switch / Mobile は別途検討が必要。

### Q. 開発資金や Kickstarter は?
**A.** 個人開発のため Kickstarter なし。Steam EA の収益で開発継続。
itch.io / Discord での投げ銭は歓迎します。

### Q. 続編・拡張 / DLC は?
**A.** フル版 1.0 リリース後、追加キャラ / 新ステージなどの拡張を
DLC として提供予定 (EA 期間中の更新は無料)。
