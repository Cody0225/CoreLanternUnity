# Ember Drake モーション試作ブリーフ

作成日: 2026-06-01  
状態: `MOTION_BRIEF`  
対象: Ember Drake L0 / ピクセルアート試作  
接続状態: Unity未接続。`RUNTIME_CANDIDATE` ではない。

## 目的

Cobalt Pup で通した手順が、別体型のキャラにも使えるか確認する。  
Ember Drake は「小型竜・弾幕型」なので、Cobalt と違って以下を重点確認する。

- MOVE/RUN: 四足狼の走りではなく、小型竜らしい軽い跳ね走りに見えるか
- ATTACK: 火弾が口/鼻先から出ているように見えるか
- 見た目: 現行の橙色の竜、黒い角、緑の目、背中の棘を維持できるか

## 維持する見た目

- 橙色の小型竜
- 大きい緑の目
- 黒い角と背中の黒い棘
- 白い腹
- 小さな前脚と太めの後脚
- 尻尾
- 弾幕型らしい火/熱のアクセント
- 右向きの3/4サイドビュー
- 現代寄りの高解像度ピクセルアート

禁止:

- 鳥、狐、恐竜の別種に寄りすぎる
- 角や背中棘を消す
- Cobalt Pup と同じ足運びにする
- 火弾が胸や手から出ているように見える

## MOVE/RUN仕様

狙い: 小型竜らしい「跳ねる前進」が読めること。

推奨フレーム設計: 6フレーム

| Frame | 状態 | 見せたい変化 |
|---|---|---|
| R1 | 接地 | 後脚が接地、前脚は軽く構える |
| R2 | 蹴り | 後脚で地面を蹴る。尻尾は少し下がる |
| R3 | 浮き | 胴体が少し上がり、前脚が前に出る |
| R4 | 着地 | 前脚が接地、後脚が追いつく |
| R5 | 反対蹴り | もう片側の後脚で蹴る。頭が少し前へ |
| R6 | 戻り | R1へ自然につながる |

NG:

- 二足キャラのように棒立ちで上下するだけ
- 足ではなく尻尾だけで動いている
- 前脚/後脚の役割が読めない

## ATTACK仕様

攻撃発生源:

- 口/鼻先固定

推奨フレーム設計: 5フレーム

| Frame | 状態 | 見せたい変化 |
|---|---|---|
| A1 | 構え | 頭を少し下げ、口を前に向ける |
| A2 | 溜め | 口/鼻先に小さい橙色の火が灯る |
| A3 | 発射 | 火弾の始点が口/鼻先に接する |
| A4 | 反動 | 頭と首が少し戻り、尻尾が遅れて動く |
| A5 | 戻り | 通常姿勢へ戻る。小さな火花だけ残る |

NG:

- 火弾が手、胸、画面中央から出る
- 口元の溜めが無い
- 本体に反動が無い
