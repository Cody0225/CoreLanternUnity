## アートスタイル

- **ピクセルアート風**（ドット絵のテイスト）。ただし解像度は512x512を保ち、
  「高解像度のピクセルアート風」にする（粗すぎるドットにしない）
- 既存のブランド世界観（サイバー/ネオン/データ生命体）と整合
- 各キャラのタイプが色とシルエットで一目で区別できる
- 商用利用前提・オリジナルIP（既存ゲームキャラに似せない）

## 🔴 タイトル6体並べ用の必須統一仕様（重要）

6体をタイトルに横並びするため、**全6体で以下を厳密に揃える**こと。
バラバラだと横一列が不揃いになり使えない。

1. **キャンバスサイズ**: 全6体 512x512 で統一
2. **キャラの足元の高さを揃える**: 全キャラの「接地点（足/体の底）」が
   キャンバス内の同じY位置に来るようにする（並べたとき足並みが揃う）
3. **キャラの占有高さを揃える**: キャンバス高に対するキャラ本体の高さ比率を
   揃える（小さい兎も大きい熊も、画面上で極端な大小差が出すぎないよう調整。
   多少の体格差はキャラ性として残してOKだが、兎が熊の1/3等にはしない）
4. **正面〜やや斜め向きで目線の高さを揃える**: 全キャラほぼ同じアングル
5. **透過PNG・四隅 alpha=0**
6. **影は内蔵しない**（タイトル側で必要なら別途付ける。キャラ単体は透過背景に本体のみ）

## 🔴 meta 生成ルール（2026-06-01 の事故再発防止・厳守）

直近、Codex 生成の素材で `.meta` が末尾改行欠落 + 改行コード不正になり、
Unity が "could not be parsed / valid GUID なし" として PNG ごと無視する不具合が
77枚発生した。**今回は絶対に繰り返さないこと。**

- **理想: PNG だけ置いて `.meta` は Unity 自動生成に任せる**（手書きmeta事故の根絶）
- どうしても meta を書くなら:
  - UTF-8 (BOMなし) / 改行コード CRLF / **末尾に改行(0x0a)を必ず付ける**
  - 既存の正常 meta（`Lantern.png.meta`）をテンプレに、GUID 行だけユニーク32桁hexに
  - 生成後、**末尾バイトが 0x0a であることを自分で検証**してから完了報告
- 既存 `Partner_S*_L0.png` を**同名上書き**する場合、対応する `.meta` は
  既存の正常なものをそのまま残す（PNG だけ差し替えれば meta は再利用される）。
  → これが一番安全（GUID も維持され、meta 破損も起きない）
