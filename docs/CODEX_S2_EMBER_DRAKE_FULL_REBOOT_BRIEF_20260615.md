## ルート文明（本体デザインで分ける・背景円や色替えに依存しない）
- **R1 SPEED = サイバー文明**：青/シアン発光・データライン・軽量装甲・空力フィン・前傾/疾走/跳躍。速さは姿勢・細身・流線で。
- **R2 POWER = 炉心金属文明**：金/橙/赤橙発光・炉心コア・鍛造重金属装甲・重関節・踏み込み/突進。強さは炉心・重さ・脚力で（人型ファイター化しない）。エンバー素体と最も親和。
- **R3 GUARD = 樹皮と蔦の自然文明**：緑/ティール/翡翠発光・樹皮/蔦/葉/苔/根・木質装甲/自然甲殻・低重心/防御姿勢。守りは自然装甲＋安定姿勢で（盾/鋼/石塊や炉心/橙発光に寄せない）。
- 発光色で一目でルートが分かること（R1青系 / R2金橙系 / R3緑系）。混同禁止（横断ルールは ROUTE_CIVILIZATION doc 参照）。

## 成長ルール（L0→L1→L2→L3 で進化が読めること）
- **L0**：素体（現行512を基準の起点として参照）。
- **L1**：各文明の萌芽。軽装・若い体格。文明モチーフは控えめに開始。
- **L2**：**体格・姿勢・シルエットを L1 から明確に変える**（装飾追加でなく形の進化）。文明モチーフが明確化。
- **L3**：通常進化の最終形。風格・密度・完成度を上げる。**ただしULTIMATE級（城塞/都市/巨大翼/ボス級/浮遊装飾）にしない**。
- L1→L2→L3 が「同一個体の成長」に見える連続性を保つ。
