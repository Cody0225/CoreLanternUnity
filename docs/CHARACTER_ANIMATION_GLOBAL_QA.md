> - 本体中央の**色サンプル**で意図の色か検証

## 目的

この文書は、Cobalt Pup だけでなく、今後作るすべての相棒・進化後・クロス進化キャラクターに適用する。

今回の失敗は「特定キャラの作画ミス」ではなく、キャラアニメーション制作全体の確認工程が弱かったことが原因。  
そのため、再発防止策は全キャラ共通ルールとして固定する。

## 絶対ルール

- キャラごとの体型・移動方式・攻撃発生源を決める前に画像生成しない。
- 指摘された問題が変わっていない素材を、修正済みとして報告しない。
- crop、再出力、ラベル変更だけを修正扱いしない。
- GIFを出す前に、RUN単体とATTACK単体を必ず目視する。
- ユーザーへ出す前に、`docs/CHARACTER_SECRETARY_REVIEW_PROTOCOL.md` の秘書レビューを通す。
- 懸念が1つでも残る場合、修正済みとして提示しない。
- 同じ問題で内部NGが2回続いたら生成を止め、短く相談する。
- ユーザーが承認するまでゲーム内接続候補にしない。

## キャラ別モーションブリーフ

各キャラの作業前に、必ず以下を埋める。

| 項目 | 内容 |
|---|---|
| キャラ名 | 例: Cobalt Pup |
| 体型 | 四足、二足、浮遊、翼あり、大型、蛇型など |
| シルエットの核 | 大耳、角、尾、羽、装甲、マントなど |
| 移動方式 | 歩行、走行、跳躍、浮遊、ホバー、這うなど |
| 動くべき部位 | 前足、後足、尻尾、羽、装甲、コアなど |
| 動いてはいけない/不自然な部位 | 固定すべき装甲、発光コアなど |
| 攻撃発生源 | 口、胸コア、角、手、武器、周囲のビットなど |
| 攻撃演出 | 弾、レーザー、突進、範囲波動、召喚など |
| 必須アニメ | Idle / Run or Move / Attack / Hit |
| NG条件 | 足が滑る、発射位置が不明、同じ足だけ動く、体だけ横滑りなど |
| 縮小確認 | 64px / 96px / 128pxで読めるか |
| 参照素材 | 元ラフ、現行ゲーム内PNG、進化先PNGなど |

このブリーフが無い状態で生成した素材は、原則 `ROUGH_REVIEW` 未満として扱う。

## 共通ゲート

### Gate 0: 指摘事項の固定

作業前に、直すべき問題を短く列挙する。

例:

- 後ろ足が一体化して見える
- 攻撃が口ではなく不明な場所から出ている
- 前回より見た目が劣化している

このリストに無い作業を優先しない。

この時点で「どのキャラの、どの部位の、どの動きが問題か」を固定する。  
問題が足運びなら足運び、攻撃発生源なら攻撃発生源に絞る。見た目全体の再描画へ勝手に広げない。

### Gate 1: ラフ品質チェック

AIラフまたは既存ラフが以下を満たすか確認する。

- キャラ名と見た目が一致している
- 既存の世界観に合う
- ゲーム内サイズでもシルエットが読める
- 進化や役割が見た目から伝わる
- 既存IPに寄りすぎていない

### Gate 2: モーション設計チェック

GIF化前に、フレームごとの動きを決める。

四足キャラなら:

- 前足と後ろ足の接地順を決める
- 後ろ足が胴体に隠れすぎないようにする
- 体だけ横に滑らせない
- 尻尾や耳は補助動作として使う

二足キャラなら:

- 左右足の接地が交互に読める
- 上半身だけ揺らして歩行扱いにしない
- 武器持ちなら武器の重さが伝わる

浮遊キャラなら:

- 足運びではなく、浮遊の上下動・回転・粒子で動きを出す
- ただ静止画を上下させるだけにしない
- 攻撃時の溜めと反動を入れる

大型キャラなら:

- 小刻みな動きにしすぎない
- 重量感のある沈み込み、反動、遅れを入れる

### Gate 3: GIF生成チェック

最低限、以下を個別に出す。

- Idle GIF
- Run / Move GIF
- Attack GIF
- Hit GIF
- 64px / 96px / 128px 縮小確認画像
- Before / After 比較画像または比較GIF

複合プレビューだけでは不十分。  
問題が起きやすいRUNとATTACKは単体GIFで確認する。

### Gate 4: 自己検収

ユーザーに見せる前に、以下を `OK / NG` で確認する。

| 項目 | 判定 |
|---|---|
| 見た目が前回より劣化していない | OK/NG |
| 指摘箇所が実際に変わった | OK/NG |
| RUNで接地や移動が読める | OK/NG |
| ATTACKの発生源が明確 | OK/NG |
| ATTACKに溜め、発射、反動、戻りがある | OK/NG |
| 文字やUIがキャラに重なっていない | OK/NG |
| 透過PNGの四隅alphaが0 | OK/NG |
| 64px/96px/128pxで読める | OK/NG |

1つでもNGなら、修正済みとして報告しない。

### Gate 5: Before / After 証明

修正報告では必ず以下を添える。

- 前回NGだった点
- 今回具体的に変えた点
- RUN単体GIF
- ATTACK単体GIF
- まだ残る懸念

前回と同じ問題が残っている場合は、「未修正」と明記する。

### Gate 6: 秘書レビュー

ユーザーへ見せる前に、秘書レビューで以下を確認する。

- ユーザーやClaudeから指摘されそうな点が残っていないか
- 気になる点があるならユーザーに出す前に止めているか
- 報告が短く、通過/停止/残る懸念に分かれているか
- `RUNTIME_CANDIDATE` と言える状態か
- 接続してよいファイル名、接続禁止ファイル名が明確か

秘書レビューでNGが出た場合、ユーザーへ成果物として提示しない。  
修正に戻すか、未修正として扱う。

### Gate 7: ランタイム候補化

ユーザーがGIFを承認してから、初めて `RUNTIME_CANDIDATE` として扱う。

それまでは以下のどれかに分類する。

- `ROUGH_REVIEW`: 見た目方向性だけ
- `MOTION_REVIEW`: 動き確認だけ
- `REJECTED`: 非採用

## 攻撃発生源のルール

攻撃発生源はキャラごとに固定する。

| タイプ | 自然な発生源 |
|---|---|
| 狼・狐・猫系 | 口、額コア、胸コア、周囲ビット |
| 竜系 | 口、角、翼、胸コア |
| 防衛型 | 盾、背中装甲、足元リング、コア |
| 魔法・連鎖型 | 尻尾、目、周囲の紋章、浮遊ビット |
| 装甲型 | 肩砲、腕、胸部、背中砲塔 |
| 浮遊/コア型 | 中心コア、周囲リング、衛星ビット |

発生源が絵として読めない場合は不採用。

## 進化後・クロス進化への適用

進化後は、素体よりも以下が増える必要がある。

- サイズ感
- 装甲量
- 発光量
- シルエットの特徴
- 攻撃の説得力

ただし、進化しても体型ルールは失わない。  
四足なら四足として動く。浮遊なら浮遊として動く。大型なら重量感を出す。

クロス進化は「メインキャラがリンク要素を吸収した姿」なので、元キャラの核とリンク要素の両方が見える必要がある。

## Claude / Codex 共有ルール

- Codexは素材生成、GIF検収、ドキュメント化までを担当する。
- Claudeはユーザー承認後のUnity接続を担当する。
- `REJECTED` や未承認の `MOTION_REVIEW` をゲーム内に接続しない。
- 接続前に、この文書と `docs/CHARACTER_PIXEL_ART_PIPELINE.md` を確認する。

## 今後の結論

Cobalt Pupだけの問題として扱わない。  
次のキャラ、進化後、クロス進化でも、同じゲートを通す。

「画像を作った」ではなく「ゲーム内で納得できる動きになった」ことを進捗とする。
