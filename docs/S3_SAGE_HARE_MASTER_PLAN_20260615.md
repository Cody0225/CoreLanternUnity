## 3. S3固有の最重要原則：「緑が主役、文明は素材とアクセントで乗せる」（2026-06-15 確定）
S3は**基体そのものが自然/緑**。**全段（L1/L2/L3）で緑をメイン色に保つ。** 文明差は"体を別色に塗り替える"のではなく、**素材（サイバーパネル/炉心金属/樹皮）＋発光アクセント色（シアン/橙/翡翠）＋形・姿勢**で出す。

- **緑＝主色を全段維持。クリーム/白は差し色（アクセント）のみ。**
  - L1: 緑優勢・クリームごく少量
  - L2: 緑優勢
  - L3: 緑がメインのまま・クリーム比率が"少し"上がる程度（それでも主役は緑）
- **禁止:** 白/クリーム/シアン主体の別キャラ化（前回S3失敗の主因）。文明の発光色（シアン/橙）が**体の主色を乗っ取る**こと。

## 4. ルート別 進化トラジェクトリ（L1→L2→L3 が一本の線として繋がること）

> L3 も新規作成（9枚reboot）。**全段で緑が主色**。文明差は素材＋発光アクセント＋形で出し、体の主色を塗り替えない（クリームはL3でやや増える程度の差し色）。L1→L2→L3が一本の線で繋がるよう設計する。

### R1 = SPEED / CYBER（緑は全段メイン）
- **L1（入口・新規）**: 緑優勢の体＋細いシアンのデータライン、小型メカパネル、耳/脚に軽い空力。細身・俊敏姿勢。クリームはごく少量の差し色。
- **L2（遷移・新規）**: 体格・姿勢を明確に変える（さらに細く流線・前傾）。シアン回路と軽量テック装甲を増やす（**装飾追加もOK**）。**体の主色は緑のまま**、シアン発光を強める。
- **L3（新規・最終形）**: サイバー兎の完成形。データライン・空力が最大。**主色は緑、クリーム差し色が少し増える程度**。シアン発光がアクセントの主役。
- 一貫: 体＝緑、サイバー＝素材＋シアン発光で表現（**体を青く塗り替えない**）。

### R2 = POWER / FURNACE（緑は全段メイン）
- **L1（入口・新規）**: 緑優勢の体＋胸に小さな炉心の灯（赤橙・控えめ）、関節/爪/耳先に熱アクセント、やや頑強。重装はまだ。クリームはごく少量。
- **L2（遷移・新規）**: 体格を頑強化（肩・脚）、炉心を拡大、金属/熱プレートを増やす（**装飾追加もOK**）、前傾の踏み込み。**体の主色は緑のまま**、橙発光・金属を強める。
- **L3（新規・最終形）**: 重装炉心獣の完成形、出力/突進。**主色は緑、クリーム差し色が少し増える程度**。炉心橙と鍛造金属がアクセントの主役。
- 一貫: 体＝緑、炉心＝橙発光＋金属で表現（**体を橙に塗り替えない**）。人型ファイター化はしない（炉心・体格・脚力で出力表現）。

### R3 = GUARD / NATURE（基体に最も近い・緑は全段メイン）
- **L1（入口・新規）**: 緑優勢、肩/背に軽い樹皮・葉・若い蔦・翡翠マークを少量。低く安定した防御姿勢。
- **L2（遷移・新規）**: 樹皮・木質装甲と蔦/根を増やし、防御的に頑強化（**装飾追加もOK**）。**体の主色は緑のまま**、樹皮褐＋翡翠をアクセントで増やす。
- **L3（新規・最終形）**: 樹皮/木質の重装ガーディアンの完成形。**主色は緑、樹皮褐＋苔緑が増えるが緑がメイン**。翡翠発光がアクセント。
- 一貫: 体＝緑、自然装甲＝樹皮褐＋蔦＋翡翠で表現。**石/鉱物/金属/炉心/橙発光は不可（R2と被らせない）。**
