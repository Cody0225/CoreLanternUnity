## 問題（なぜ作り直すか）

タイトルに6体並べたところ、**Hex Cat (S4) と Drift Fox (S5) だけ「べた塗り」**で、
他4体（Cobalt / Ember / Sage / Iron）にある陰影・ハイライト・立体感が無い。

経緯（2段階で破損）:
1. 初回生成: 陰影は良かったが、透過の色抜きで**色が灰色/銀色に飛んだ**
   （Hex Cat=グレー猫、Drift Fox=銀＋水色。紫でも桃でもない）
2. 色修復パス: 色は紫/桃に戻したが、**上から再塗りしたため陰影が潰れて単色化**

→ パッチの重ね掛けでは直らない。**最初から正しい色で、陰影込みで描き直す。**

## 要件

1. **デザイン・ポーズ・シルエットは現行のまま維持**（猫＝六角ジェム＋しっぽ、狐＝ふさふさ尾）。
   キャラ設計は良いので変えない。直すのは「色」と「陰影」だけ。
2. **色は最初からベイクして描く**（後から色を抜かない・後から塗らない）:
   - S4 = はっきりした紫の猫（影=濃紫 / 地=紫 / ハイライト=明るい紫 / 差し色=白系ジェム）
   - S5 = はっきりした桃色の狐（影=濃いピンク / 地=ピンク / ハイライト=明るいピンク / 白い差し色）
3. **陰影は他4体と同等のセルシェード**: 影・中間・ハイライトの**最低3階調**＋濃い輪郭線。
   単一色のべた塗り厳禁。**基準は Cobalt Pup (S1) / Ember Drake (S2) の立体感**。
4. **透過は透明キャンバスに直接描く**（chromakey の背景色抜きは使わない＝色飛びの原因）。
5. 統一仕様（他4体と揃える・崩さない）:
   - 512x512 / 接地点 `bottom_y = 448` / 占有高さ 327〜333 / 四隅 alpha=0
   - 本体ベタ部 alpha ≥ 230（透けスカスカ禁止）/ 内部に透け穴なし / 孤立ゴミ画素なし
6. **PNG のみ同名上書き。`.meta` は触らない**（既存meta再利用でGUID維持・末尾0a維持）。
7. 修正前にバックアップ。**6体横並びプレビュー + 縮小チェックを再出力。**
