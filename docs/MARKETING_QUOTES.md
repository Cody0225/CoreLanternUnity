## 📋 引用ポリシー

### 公開 (= 引用 OK) の判断基準
- ✅ 公開 SNS (Twitter / Threads / Bluesky 等) の公開投稿
- ✅ Steam レビュー (公開済)
- ✅ itch.io コメント (公開済)
- ✅ Discord public channel (チャネル運営方針による)
- ✅ YouTube/Twitch 配信中の発言 (録画公開分)

### 許可が必要 (= 引用前に連絡推奨)
- ⚠ DM・メール等の私信
- ⚠ Discord private channel
- ⚠ ベータテスター向け限定発言

### 引用時の表記
```
"<quote text>"
— <Author>, <Source/Platform>, <Date>
```

例:
```
"防衛とサバイバーの組み合わせが新鮮で、つい何度もリトライしてしまう"
— @example_user, Twitter, 2026-08-20
```

## 📈 引用素材化フロー

### Step 1: 検出 (毎日)
- Twitter / X で `Eggcore Protocol` `Embercore` `eggcore_demo` 等で検索
- Steam フォーラム / レビュー巡回
- itch.io コメント確認
- YouTube / Twitch 検索

### Step 2: 評価
- 「これは強い感想だ」と思ったら本ファイルに追加
- カテゴリ分類 (A-G)
- Permission 確認 (公開投稿か / 私信か)

### Step 3: 許可取得 (必要時)
- 私信や限定チャネルの場合、引用元に連絡
- 例文:
  ```
  Thank you for your kind words about Eggcore Protocol! 
  Would it be OK if we featured your quote on our Steam 
  store page or press materials? You'll be credited as 
  [name/handle]. No worries if you'd prefer we didn't.
  ```

### Step 4: 採用
- Featured Quotes セクションに昇格
- Steam ストア / プレスキット / SNS に転載
- 引用先に「掲載しました」と通知

## 🚫 注意事項

### 引用してはいけないもの
- ❌ 他社競合製品 (VS や Brotato) の悪口を含む引用
- ❌ ネタバレ過剰な内容 (Wave 10 のオチ等)
- ❌ 個人攻撃や誹謗中傷
- ❌ ライセンス不明の画像/動画スクショ

### 改変ルール
- 短縮 OK (`...` で省略可)
- 文法修正 OK (英語の typo 等)
- **意味の改変は NG** (ネガをポジに変える等)
