## 🔍 計測方法

### Steam Partner Portal
- ダウンロード数: `Sales & Activations` ページ
- レビュー: `Community Hub` の review summary
- フォロワー: `Marketing → Community` ページ
- 売上: `Reports → Sales Report`

### itch.io
- ダウンロード数: Dashboard → Project → Stats
- コメント数: Project → Community

### Twitter / X
- フォロワー数: プロフィールページ
- 投稿のインプレッション: Analytics

### Discord
- メンバー数: サーバー設定 → Members

### YouTube (実況・レビュー)
- 「Eggcore Protocol」を検索
- アップロード日と再生数を記録

### ゲーム内データ (将来オプション)
将来的に Steam API で:
- アチーブメント解除率
- プレイ時間統計
- キャラ別選択率
を取得可能。初期は手動でも OK。

## 📋 重要な KPI と意思決定

| KPI | 閾値 | 閾値を超えたら |
|---|---|---|
| **返金率 < 5%** | 良好 | 継続 |
| **返金率 5-10%** | 注意 | 返金理由分析 → 改善 |
| **返金率 > 10%** | 危険 | 緊急パッチ + Hotfix |
| **レビュー Pos 率 < 70%** | 注意 | ネガレビュー全件分析 |
| **レビュー Pos 率 < 50%** | 危険 | 大型アップデート + 価格再検討 |
| **DL 数 (初週) < 50** | 注意 | マーケ強化 (SNS / 配信者) |
| **DL 数 (初週) > 200** | 良好 | コミュニティ強化 (Discord) |
| **DL 数 (初月) > 1000** | 大成功 | 拡張計画前倒し検討 |
