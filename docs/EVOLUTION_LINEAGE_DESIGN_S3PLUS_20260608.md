## A. 共通ルール（全素体・全段階で固定）
### ルート言語（R1/R2/R3 = 固定）
- R1 SPEED: 連射・移動・貫通。流線フィン/ブレード/シアン光/前傾姿勢。
- R2 POWER: 一撃・バースト・対ボス。重装甲/砲/角/橙熱/低姿勢。
- R3 GUARD: コア耐久・回復・反射・ノックバック。盾板/緑金装甲/安定姿勢。

### 成長ルール（L0→L3 = 固定）
- L0 ベース: 素の姿。ルート未分化。種の頭・目・基色・発光コアが分かる。
- L1 芽生え: 該当ルートの兆候（小さな装備/形態変化）。まだ幼い。
- L2 顕在化: ルート固有の武器/装甲/形態がはっきり。青年体。
- L3 完成形: 成体・最強の見た目。シルエットだけで route 即判別。

### 不変条件（全 S3+ で必達）
- 各段階は **シルエットで差別化（色替えだけ禁止）**。
- 種アイデンティティ（頭・目・基色・発光コア）を全段階で継承。
- ULTIMATE(F*_L3) は route L3 より明確に上位に見える。
- **各素体の R1/R2/R3 は、同じ L0 から派生した分岐進化であり、別キャラ化は禁止。**
  **ルート差は色ではなく、体型・姿勢・武器/装甲器官・翼/尾/頭部シルエットで出す。**

## C. S7–S11（拡張提案・要承認 / 現状テーマのみ・route未確定）
※54本の量産前に route アイデンティティ承認が必要（マスター方針）。名称は仮。

### S7 Wraith Lynx（近接型・霊影の山猫）
- テーマ: オーラ＋吸血で近距離制圧する霊影リンクス。
- R1: 高速接近・オーラ斬 / R2: 吸血ヘビーストライク / R3: オーラ防壁＋吸収
- 成長: 幼い山猫 → オーラをまとう成体 → 吸血オーラ完成の霊影リンクス
- 注意: リンクス（山猫）として統一。狼と混ぜない（房付きの耳・短い尾・山猫体型）。

### S8 Genesis Core（全種解放型・隠し総合）
- テーマ: 4リンク内蔵の万能。条件解放の隠し。
- R1 SPEED: 多面コアが高速展開する機動型。細身・分割フィン・高速共鳴。
- R2 POWER: 中央コアが巨大化した高出力型。重い胴体・高火力結晶砲。
- R3 GUARD: 外殻コアが厚く閉じる防御型。殻・装甲・守護結晶。
- 注意: 3ルートすべて万能だが、**シルエットは必ず差別化する**。コアは「図形貼付」でなく有機的な生体結晶として描く。
- 成長: 生体コア → 多面結晶体 → 全種共鳴体。

### S9 Halo Caster（ファンネル型・自律ビット）
- テーマ: 周回攻撃＋離脱突撃ビット。
- R1: ビット周回連射 / R2: ビット集束の離脱突撃 / R3: ビット防御陣
- 成長: 単ビット → 複数ビット → ビット群。
- 注意（強化）: **ビットは本体から完全に分離した浮遊円・UIリング・魔法陣にしない。**
  **本体の背部・尾・肩・翼状アームに接続されたビット器官として描く。**

### S10 Pulse Hydra（レーザー型・貫通）
- テーマ: 直線貫通レーザーの高火力。
- R1: 速射レーザー / R2: 極太貫通ビーム / R3: 多頭防衛レーザー
- 成長: 単頭 → 双頭 → 多頭。

### S11 Solar Anchor（コア共鳴型・TD特化）
- テーマ: コア周りに常時ダメージ圏。
- R1: 機動共鳴 / R2: 高出力共鳴砲 / R3（主）: コア要塞共鳴
- 成長: 共鳴器官の芽 → 増設 → 完成。
- 注意（強化）: **リングは魔法陣や UI リングにしない。本体装甲・背部器官・胸部共鳴器として内包する。**
  **本体から離れた円形エフェクトは禁止。**
