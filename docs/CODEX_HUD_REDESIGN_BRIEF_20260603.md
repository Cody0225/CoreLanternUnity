## 人気ゲームHUDの分析（このジャンル＝サバイバー×TDログライト）

| ゲーム | HUDの要点 | 学べること |
|---|---|---|
| **Vampire Survivors** | 画面最上部に極細のXPバー1本／中央上にタイマー／隅に小さなカウンタのみ | 徹底した最小限。中央は完全に空けて戦闘を見せる。XPは細い帯 |
| **Brotato** | アイコン駆動の小さなステータス群／上中央にウェーブ・タイマー／HPはキャラ近く | アイコン＋数字（長い文字ラベルを使わない）。コンパクト |
| **Hades** | HPが大きく目立つ／能力アイコンを1か所に集約／装飾枠は上品 | 最重要情報(HP)を最も大きく。装飾は控えめで統一 |
| **Risk of Rain 2** | 下にHPバー／左下にアイテム列／左上に通貨 | 情報を画面の端に寄せ、中央を空ける。グルーピング |
| **Diablo / PoE** | HP/リソースを球(オーブ)で一目表示／スキルバー下部 | 一目で読める形。色で即判別 |
| **Kingdom Rush（TD）** | 上に資源/ライフ/ウェーブを横一列／角丸のクリーンなパネル | 親しみやすい角丸・フラット。テック装飾を盛りすぎない |

### 共通する「良いHUD」の原則
1. **最小限・端に寄せる** — 中央は空ける。HUDは画面の縁・隅にまとめる
2. **アイコン＋数字 > 長い文字ラベル**
3. **視覚階層** — 最重要(HP)を最大・最も明るく、副次情報は小さく暗く
4. **統一されたビジュアル言語** — 枠・書体・配色を1系統に。混ぜない
5. **装飾は控えめ** — 角ブラケットを全パネルに付けない。質感は素材感で出す
6. **可読性最優先** — 半透明の暗い下地＋高コントラスト文字、バーは明確な塗り色
7. **グルーピング** — 関連情報を1クラスタに（HPとコアHPは隣接）

## ビジュアルデザイン分析（デザイン面＝今ダサい部分）

### なぜ今のHUDが安く見えるか（原因）
1. **「無料SF UIキット」感**: 細いネオン枠＋角のL字ブラケットを全パネルに均一適用。
   この角ブラケットは“いかにも素材集”の典型で、最も安っぽさを出している
2. **質感(マテリアル)が無い**: 完全フラットな箱。素材の厚み・透け・陰影が無いので紙っぽい
3. **彩度の出しすぎ**: 枠も文字もネオンで光らせ気味 → 統一感がなく騒がしい
4. **余白不足・精度のばらつき**: 文字が枠に近い、線が太い → 雑に見える
5. **バーが単純な平塗りグラデ**: 溝(へこみ)やハイライトの段が無く、立体感ゼロ

### 高級に見えるHUDの「作法」（AAA分析）
| 作法 | 具体 | 参考 |
|---|---|---|
| **マテリアル（質感）** | フロスト/すりガラス・微グラデ・内側の柔らかい影で「本物の素材」感 | Returnal, Destiny 2 |
| **抑制（リストレイント）** | 装飾を足さない。1pxヘアライン＋整列＋余白で“精度”を見せる | Apex, Valorant, Returnal |
| **彩度の規律** | 下地は脱彩色のダーク、彩度は「バーの塗り3色＋小アクセント」だけに集中 | Destiny 2, Cyberpunk |
| **グロウは点だけ** | 光らせるのはバー先端とアクセント線のみ。全面発光は安っぽい | Destiny 2 |
| **角・縁の処理** | 一定の小さな角丸 or 上品な面取りを“全要素で統一”。L字ブラケットは使わない | Apex, LoL |
| **タイポgrafi** | 1書体・ウェイト階層・等幅数字(HP 11/11がガタつかない) | Destiny 2, Cyberpunk |
| **余白と深度** | 文字に余白、UIは盤面にごく薄い影を落として“前面”に浮かせる | Hades, Diablo IV |
| **クラフト感** | 専用アイコン・一貫したディテール（量産素材の寄せ集めにしない） | Hades |

要するに：**「光らせて飾る」=安い／「素材の質感＋抑制＋精度」=高級**。

## Eggcore Protocol HUD 新デザイン仕様（プレミアム・サイバー）

方向性 = **「静かで上質なサイバーUI」**（Returnal / Destiny 2 の落ち着いた高級感）。
飾るのではなく、**マテリアル＋抑制＋精度**で高く見せる。

### マテリアル（質感）— ここが最重要
- **すりガラスの暗いスラブ**: 下地 `#0B1418` を alpha 0.60〜0.70、
  上→下のごく微妙なグラデ（上端がわずかに明るい）。上端内側に 1px のハイライト線、
  下側はわずかに沈む内側影。＝薄いガラス板のような“厚み”を出す（ベタ箱にしない）
- 盤面との分離に、パネル全体へ**ごく淡いドロップシャドウ**（UIが前面に浮く）

### 枠・角・線
- 枠は **1px の極細ヘアライン**、色は**脱彩色の青灰**（例 `#3A5A66` を低alpha）。ネオンにしない
- **角のL字ブラケットは廃止**。代わりに**一定の小さな角丸**で全要素を統一
- カテゴリ表示は**上端にだけ 2px のアクセント色の短い線/タブ**（種別の目印）。四方を光らせない

### 配色の規律
- 下地・枠＝**脱彩色のダーク／青灰**でほぼモノトーン
- 彩度を使うのは **バーの塗り3色＋ごく小さなアクセント**だけ:
  自分HP=コア青白 `#8BC8FF` / コアHP=アンバー `#FFCE3B` / EXP=緑 `#6BFF9E`
- 全面ネオン・虹色は禁止

### 文字（タイポ）
- 1書体で統一（ロゴと同系の幾何サンセリフ）。**等幅数字**で `11/11` がガタつかない
- ラベルは小さめ・70%白で控えめ、数値は明るく。ウェイトで階層をつける
- 文字の周りに**余白**（枠ギリギリに置かない）

### グロウ
- 光らせるのは**バーの先端**と**上端アクセント線**だけ。ごく弱く。全面発光は禁止

### パネル（4種・512x512・9-slice border=24 据え置き）
- `HUD9_Panel_Wave` / `HUD9_Panel_HP` / `HUD9_Panel_Level` / `HUD9_Panel_ChipMini`
- 中身: **半透明ダークガラス＋1pxヘアライン枠＋上辺のアクセント細線**だけ。
  角ブラケット・ネオン装飾・斜めカットなどの「うるさい」要素は入れない
- 中央は素直な平面（テキストが最も読める）。四隅 alpha=0

### バー（4種・256x64・9-slice border=12/8 据え置き）
- `HUD9_Bar_Back`（下地）/ `HUD9_Bar_HP_PlayerFill`(シアン) / `HUD9_Bar_HP_CoreFill`(アンバー) /
  `HUD9_Bar_EXP_Fill`(緑)
- 形: **角丸のクリーンなバー**。下地は暗い溝、fillは明るい単色＋ごく薄い上方ハイライト（1段）
- 引き伸ばし耐性のため左右は無地（9-sliceの中央が伸びる前提）。ギラギラ装飾なし

### Wave進行バー（512x48・border16/8 据え置き）
- 同じ言語で。細いクリーンな帯＋進捗fill。Boss時はアンバー寄り

### アイコン（任意・あれば統一セット）
- HP/コア/EXP/データの極小グリフを同一タッチで。無ければ現行アイコン流用可
