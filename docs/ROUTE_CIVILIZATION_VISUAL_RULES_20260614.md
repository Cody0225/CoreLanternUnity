# ルート文明ビジュアルルール（通常進化 R1/R2/R3 共通・固定）— 2026-06-14

位置づけ: **通常進化ルート（R1 SPEED / R2 POWER / R3 GUARD）の見た目を分ける最上位の共通基準。**
適用範囲: 全素体（S1〜S11）の通常進化 R1/R2/R3。Codex の raw 生成、Claude の TECH_FIX 検収、ChatGPT/ユーザーのレビューで**共通の合否基準**として使う。
状態: **固定（FIXED）。** 以後の R1/R2/R3 はこのルールに沿わせる。準拠: 品質ゲート13項目／各素体の種DNA（顔・体型・基調色）。

> ⚠️ ルートは「色替え」ではなく **文明（世界観）＋発光色＋素材＋姿勢** で分ける。同じ素体でも、属する“文明”が異なる。

---

## R1 SPEED = サイバー文明

テーマ: 高速・データ・流線。速さは「姿勢・細身・流線パーツ」で見せる（巨大化や武器盛りでは見せない）。

必須要素:
- **青／シアン発光**
- **データライン**（回路・走査線的な発光ライン）
- **軽量装甲**（薄く絞ったプレート）
- **空力フィン**（流線的なフィン/エッジ）
- **前傾・疾走・跳躍**の姿勢、細身のシルエット

禁止／回避要素:
- 重金属の重装甲、炉心コア、橙/赤橙発光（→ POWER 寄り）
- 樹皮・蔦・苔などの自然装甲（→ GUARD 寄り）
- 巨大化・要塞・城・浮遊リング・魔法陣・粒子・スピード線・UI・文字
- 速さを「大きな武器」や「派手なエフェクト」で表現すること

## R2 POWER = 炉心金属文明

テーマ: 一撃・出力・重量。強さは「炉心・重さ・脚力・突進力」で見せる（人型の拳・ボクシングでは見せない）。

必須要素:
- **金／橙／赤橙発光**
- **炉心コア**（胸/胴の出力炉）
- **鍛造金属・重金属装甲**（厚いプレート、鍛えた金属質感）
- **重い関節**
- **後脚・踏み込み・蹴撃**を活かした接地姿勢、突進力を感じる体勢

禁止／回避要素:
- **二足人型のファイター/ボクサー化**（拳で殴る人型シルエット）。素体の獣シルエット（四足/半四足）を維持する
- 青/シアンのサイバー発光・データライン・空力フィン（→ SPEED 寄り）
- 樹皮・蔦・苔などの自然装甲（→ GUARD 寄り）
- 浮遊リング・魔法陣・粒子・スピード線・UI・文字、ULTIMATE級の要塞/都市

## R3 GUARD = 樹皮と蔦の自然文明

テーマ: 防御・安定・自然。守りは「自然装甲＋安定姿勢」で見せる（盾/バリア/鋼鉄/石の塊では見せない）。

必須要素:
- **緑／ティール／翡翠発光**
- **樹皮・蔦・葉・苔・根**
- **木質装甲・自然甲殻**（生体的・植物的な防御）
- **低重心・防御姿勢**（低く構えた安定したスタンス）

禁止／回避要素:
- **金属板・鉱石装甲・鋼鉄プレート・炉心コア・橙発光**（→ POWER 寄り。GUARD では禁止寄り）
- 青/シアンのサイバー発光・データライン（→ SPEED 寄り）
- 手持ち盾・エネルギーバリア・魔法陣リングで守りを表現すること
- 浮遊リング・魔法陣・粒子・スピード線・UI・文字、ULTIMATE級の要塞/都市

## 横断ルール（混同防止）

1. **GUARD で石を主素材にしない。**
   - 石を使う場合でも **苔むした自然石／土中の小さな岩片程度の補助**まで。岩塊・鉱石装甲・石壁ゴーレム化は不可。
2. **POWER の金属/炉心と GUARD の自然装甲を混同しない。**
   - 金属プレート・炉心コア・橙発光 = POWER の語彙。GUARD には持ち込まない。
   - 樹皮・蔦・木質・翡翠発光 = GUARD の語彙。POWER には持ち込まない。
3. **発光色でルートが一目で分かること。** R1=青/シアン、R2=金/橙/赤橙、R3=緑/ティール/翡翠。
4. **素体の種DNAは全ルートで維持。** 顔・基本体型・基調色・象徴器官（例: Sage Hare の長耳）は3ルート共通で残す。ルート差は「文明・発光・素材・姿勢」で出す。
5. **通常L3はULTIMATE級にしない。** 城塞・都市・巨大翼・ボス級・浮遊装飾は通常進化では使わない（F系 ULTIMATE 専用）。

## 補足ルール: L2/L3 の二足・半二足歩行について（2026-06-14 追記）

L2/L3 では、**進化感・成熟感・戦闘力が出るなら二足歩行／半二足歩行になってもOK**。二足化そのものは NG ではない。

判断基準:
- **OK**: 「その種族が進化した姿」に見える（種DNA＝顔・体型の名残・基調色・象徴器官が残っている）。
- **NG**: 「別種族の人型キャラ」に見える。

二足/半二足でも以下は NG:
- 元種族のDNAが消える。
- ただの人型ファイターになる。
- 腕や拳だけで強さを表現する（特に **POWER は炉心・重さ・脚力・突進**で見せる原則を維持）。
- R1/R2/R3 のルート文明差（発光色・素材・姿勢）が読めなくなる。
- 通常L3なのに ULTIMATE 級に豪華化する。

※ 本補足により、上記「R2 POWER 禁止要素」の**獣シルエット（四足/半四足）維持は緩和**される：二足/半二足でも、種DNAが残り・人型ファイター化せず・ルート文明差が読めるなら可。L0/L1 など幼体は従来どおり素体の獣体型を基本とする。

## 運用フロー（共通基準としての使い方）

- **Codex（raw生成）**: 上記の文明・必須要素・禁止要素・姿勢に沿って生成。背景・文字・UI・複数体・ポスター化はしない。
- **Claude（TECH_FIX 検収）**: 512×512 / RGBA / 透過 / 四隅alpha0 / 外周2px漏れ0 / 中央配置（非正方形はアスペクト比保持でフィット）に整えたうえで、**この文明ルールに照らしてルート適合を判定**。色替えだけ・文明混同・ULTIMATE過剰は差し戻し。
- **ChatGPT/ユーザー（レビュー）**: 本ルールを合否基準に、HOLD / 採用候補 / retake を判断。
