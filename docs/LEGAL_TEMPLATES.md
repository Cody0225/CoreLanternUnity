# 第 2 部: プライバシーポリシー (Privacy Policy)

## 1. 収集する情報

当スタジオは、本ソフトウェアの利用に関して **個人情報を収集していません**。

ローカル PC に保存される情報:
- ゲーム進行データ (PlayerPrefs に保存)
  - ハイスコア / アンロック状況 / オプション設定
  - 保存先: Windows レジストリ `HKEY_CURRENT_USER\Software\Embercore Studio\Eggcore Protocol`

**サーバー送信される情報: 一切なし**

- Steam: https://store.steampowered.com/privacy_agreement/

本ソフトウェアおよび当スタジオ Web サイトでは、現時点で
**クッキーやトラッキングスクリプトを使用していません**。

将来 Web サイトに Google Analytics 等を導入する場合、本ポリシーを更新します。

## 4. 第三者への提供

当スタジオは、利用者の情報を **第三者に提供していません** (そもそも収集していません)。

## 5. 子どものプライバシー

保護者の同意のもとでの利用を推奨します。
