# Codex 発注: 相棒ピクセルアート ゴミピクセル除去 (S4 Hex Cat / S5 Drift Fox)

作成: 2026-06-02
担当境界: Codex が素材修正。cs は触らない。

---

## 目的

2026-06-02 に生成した相棒6体ピクセルアートのうち、**Partner_S4_L0.png (Hex Cat) と
Partner_S5_L0.png (Drift Fox)** に、chromakey/透過処理の残りカスと思われる
微小なゴミピクセルがある。タイトル画面に大きく表示するため除去する。

具体的に確認された症状:
- **Drift Fox (S5)**: 左側に短い縦線アーティファクト、しっぽ上あたりに浮いた四角片
- **Hex Cat (S4)**: 右端中央付近に分離した小さなピクセル塊

念のため**6体すべて**をスキャンし、本体から分離した孤立ピクセル・浮遊片・
端の細線を除去すること。

---

## 修正ルール

1. **本体は一切変えない**。除去するのは「本体から分離した孤立クラスタ / 浮遊ピクセル /
   端のchromakey残り細線」のみ。キャラのシルエット・色・ディテールは保持
2. **判定の目安**: 本体の連結成分(最大の不透明領域)から離れた小さな不透明塊を
   透明化する。小さな閾値(例: 面積 N px 未満の孤立成分)で機械的に除去してよいが、
   除去後に必ず目視で本体が欠けていないか確認
3. 以下の統一仕様を**維持**(壊さない):
   - 512x512 / 接地点 `bottom_y = 448` / 占有高さ比率 / 四隅 alpha=0
4. **PNG のみ同名上書き**。`.meta` は触らない(既存meta再利用でGUID維持・破損なし)
5. 修正前にバックアップを取る

---

## 検収基準

1. S4 / S5 の孤立ゴミピクセルが消えている(本体は無傷)
2. 6体すべて 512x512 / bottom_y=448 / 四隅alpha=0 を維持
3. `.meta` 末尾バイトが 0x0a のまま(= 触っていない)/ PNG同名上書きのみ
4. 修正後の6体横並びプレビューを再出力
   (`Assets/ArtSource/CharacterPixelArt_20260601/`)
