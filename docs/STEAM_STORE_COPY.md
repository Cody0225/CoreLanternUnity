## 4. 詳細ディスクリプション (Steam ページ本文)

```
═══════════════════════════════════════
■ コアを守れ。10 Wave の防衛戦
═══════════════════════════════════════

『Eggcore Protocol』は、中央のコア「データエッグ」を守りながら
押し寄せる敵を撃退する、防衛 × ローグライト × サバイバー の融合作品。

プレイヤーは自動射撃する相棒として、コアの周囲を動き回り、
データを集め、モジュールを取得し、進化を重ねて 10 Wave を生き残ります。

1 ラン約 15-20 分。気軽に始めて、深く沼れるリプレイ性。

═══════════════════════════════════════
■ 主な機能
═══════════════════════════════════════

◆ 11 種の個性的な相棒
   バランス型 Cobalt Pup から、コア共鳴型 Solar Anchor まで。
   それぞれ専用シグネチャ機構 (ファンネル / レーザー / オーラ等) を持つ。

◆ 3 ルート進化 + 6 種のクロス進化
   SPEED / POWER / GUARD の 3 ルート × 4 段階 (L0→L3)。
   さらに条件達成で 6 種のクロス進化 (Nova Aegis 等) へ。

◆ 5 ステージ + 専用敵 + 専用ハザード
   • Stage 1: Lantern Field — 標準防衛
   • Stage 2: Lava Cache — 溶岩 + 熱風
   • Stage 3: Broken Core Network — 汚染 + リレー報酬
   • Stage 4: Frost Vault — 凍結クリスタル + 減速パッチ
   • Stage 5: Storm Spire — ランダム雷撃

◆ ボス Phase 2 + 中ボス Enrage
   Wave 5 Pulswyrm: HP 50% で enrage、弾幕強化 + 突進。
   Wave 10 Nullwyrm: HP 50% で Phase 2 突入。
   Spiral Corruption / Core Mark / Glitch Summon の新パターン解放。

◆ プレイヤーフレンドリーな選択肢
   • Reroll / Lock / Banish: Brotato 流のカード管理
   • 同設定再戦: 1 ボタンで前回構成のまま再挑戦
   • Danger Level 0-5: 自分に合った難易度を選択
   • アクセシビリティ補正

◆ 60 種以上のモジュール + 15 種のレリック
   POWER だけでなく SPEED / GUARD 専用ビルドも強力。
   キャラ固有シグネチャ強化、クロス進化専用モジュールも。
```
