# CoreLanternUnity Sound Asset Candidates

Last updated: 2026-05-22

This is a candidate list for placeholder-to-midterm audio. Before importing into a commercial build, re-open each asset page and save the license/credit text with the downloaded file.

## Source Policy

Preferred source priority:

1. CC0 packs from Kenney or OpenGameArt.
2. DOVA-SYNDROME tracks if used as background music under their license and composer conditions.
3. Freesound only with `CC0` or `CC BY`, never `NC` for commercial builds.
4. Pixabay only after checking the exact item page and keeping the license certificate, because uploads can vary and Content ID risk exists.

AI generation policy:

1. Stable Audio 3.0 is the first AI candidate for custom BGM/SE, because Stability AI states that outputs can be distributed and commercialized under the Community License, with Enterprise required for organizations above USD $1M annual revenue.
2. Eleven Music is a paid-plan commercial candidate, but do not treat it as the free-commercial default until the current plan/terms for game usage are saved with the generated file.
3. Suno Free is not suitable for this project because the official pricing page lists no commercial use for the free plan.
4. For any AI-generated audio, save the prompt, service name, plan/license, generation date, and source terms URL in `docs/AUDIO_LICENSE_LOG_TEMPLATE.md` format.

Not suitable:

- `classroom.google.com` is not an audio asset library and should not be used as a sound source.
- Suno Free outputs for commercial builds.
- AI outputs generated while logged out or on a plan whose commercial rights are unclear.

## Import Checklist

- Download audio manually from the source page; do not hotlink files.
- Save a text file beside imported audio with URL, author, title, license, and download date.
- Normalize SE volume after import.
- Keep BGM in `StreamingAssets` or an audio folder with clear naming if later split into scenes.
- Avoid using many different libraries in the final build; a unified audio identity matters more than variety.
- Replace placeholder candidates with custom commissioned audio before a serious commercial release if budget allows.
