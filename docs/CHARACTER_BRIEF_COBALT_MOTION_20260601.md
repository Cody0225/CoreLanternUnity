# Cobalt Pup モーション修正ブリーフ

作成日: 2026-06-01  
状態: `MOTION_BRIEF`  
対象: Cobalt Pup L0 / ピクセルアート試作  
接続状態: Unity未接続。`RUNTIME_CANDIDATE` ではない。

## 目的

Cobalt Pup の見た目を作り直すのではなく、ユーザーが指摘した以下の2点だけを直す。

- RUN: 後ろ足の動きが不自然。同じ足だけで動いているように見える。
- ATTACK: 攻撃が口ではない場所から出ているように見える。

今回の成功は「画像を生成したこと」ではなく、RUN単体GIFとATTACK単体GIFでこの2点が実際に改善して見えること。

## 維持する見た目

現在の良い方向性は維持する。

- 青い小型サイバー狼/狐系の相棒
- 大きい白い耳
- 白い顔/頬毛
- 青い装甲と黒い機械パーツ
- 額・胸・肩周りのシアン発光
- ふさふさした青い尻尾
- 右向きの3/4サイドビュー
- 現代寄りの高解像度ピクセルアート

以下は禁止。

- 低解像度の単純なドットへ劣化させる
- 丸いマスコットだけに簡略化する
- 既存ラフより顔、耳、装甲、発光の魅力を落とす
- RUN/ATTACK修正を理由に別キャラへ redesign する

## モーション仕様

### 体型

- 四足歩行
- 小型で軽快
- 装甲はあるが、機敏な相棒として動く

### RUN

狙い: 「走っている」と一目で読めること。

必須:

- 前左 + 後右、前右 + 後左の対角ペアで足が動く
- 後ろ足2本の役割が読める
- 接地足と浮いている足がフレームごとに分かる
- 胴体が足運びに合わせて軽く上下する
- 尻尾と耳は補助的に揺れるが、足運びのごまかしにしない
- 影は接地感を補助する。体だけ横滑りに見せない

NG:

- 同じ足だけが前後して見える
- 後ろ足が胴体に隠れ、ただ滑っているように見える
- 静止絵を横にずらしただけに見える
- 尻尾や耳だけが動き、足が動いていない

推奨フレーム設計: 6フレームループ

| Frame | 接地/浮遊 | 見せたい変化 |
|---|---|---|
| R1 | 前左 + 後右が接地、前右 + 後左が浮く | 低い姿勢。後右足を胴体の後方で明確に見せる |
| R2 | 前左が押し出し、後右が蹴る | 胴体が少し前へ沈む。後ろ足の蹴りを強める |
| R3 | 全足が切り替わる中間 | 胴体が少し上がる。尻尾は遅れて上がる |
| R4 | 前右 + 後左が接地、前左 + 後右が浮く | R1と反対ペア。後左足を胴体下ではなく後方寄りに見せる |
| R5 | 前右が押し出し、後左が蹴る | 頭と耳が少し下がる。足先の白い爪を読ませる |
| R6 | 全足が戻る中間 | 次のR1へ自然につながる。影は中央に戻す |

内部チェック:

- R1/R4を並べたとき、後ろ足の接地ペアが入れ替わっていること。
- R2/R5を並べたとき、同じ後ろ足だけが蹴っていないこと。
- 64px縮小でも、前脚と後脚の白い足先が2か所以上読めること。

### ATTACK

狙い: 口元から攻撃していると一目で分かること。

攻撃発生源:

- 口/マズル固定

必須:

- 溜め: 口元にシアンの光が集まる
- 発射: 弾またはビームが口元から出る
- 反動: 頭、首、前脚、胴体に小さな反動が出る
- 戻り: 攻撃後に自然に通常姿勢へ戻る
- 胸コア発射に見えないよう、胸コアの発光は控えめにする

NG:

- 胸や前脚、画面中央から撃っているように見える
- 発射エフェクトだけが動き、本体が反応していない
- 口元の溜めが無く、発生源が不明
- 口元より下や前脚付近から弾が出る

推奨フレーム設計: 5フレーム

| Frame | 状態 | 見せたい変化 |
|---|---|---|
| A1 | 構え | 頭を少し下げ、口元を前に向ける。胸コアは通常輝度 |
| A2 | 溜め | 口元に小さなシアン光。光はマズルに接している |
| A3 | 発射 | 弾/ビームの始点が口元ピクセルに接する。胸や前脚から離して描く |
| A4 | 反動 | 頭と首が少し後ろへ戻り、前脚が踏ん張る。弾は口元から離れて進む |
| A5 | 戻り | Idle/Runへ戻れる姿勢。余韻の小粒子だけ残す |

内部チェック:

- A2/A3で、光の中心が胸コアより明らかに上、口元にあること。
- A3で、弾の左端が口元に触れており、前脚や胸から始まっていないこと。
- A4で、本体側に反動があり、弾だけのアニメになっていないこと。

## 検収ゲート

| 項目 | 条件 |
|---|---|
| 見た目 | 既存ラフより劣化していない |
| RUN差分 | 前回NGから後ろ足の見え方が実際に変わっている |
| RUN自然さ | 接地と浮き足が読める |
| ATTACK差分 | 前回NGから攻撃発生源が実際に変わっている |
| ATTACK自然さ | 口元の溜め、発射、反動、戻りがある |
| 縮小表示 | 64px / 96px / 128pxで顔とシルエットが読める |

| 接続可否 | ユーザー承認前は `MOTION_REVIEW` まで |

1つでもNGなら、修正済みとして提示しない。

## 内部停止ルール

- 同じ問題で内部NGが2回続いたら生成を止める。
- その場合は、微妙なGIFを出さず「足運び優先で手描き補正するか、AIラフを再生成するか」だけ短く相談する。
- crop、再出力、ラベル変更だけの場合は修正扱いしない。
