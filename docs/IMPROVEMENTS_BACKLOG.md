# 改善点バックログ（バッチ実行用）

目的: ゲームの改善点（バランス・挙動・QoL・新要素・バグ）を貯めておき、
**まとめて一気に（バッチで）** 消化するためのリスト。

使い方:
1. ユーザーが思いついた改善点を、ラフな箇条書きでこの下に投げる（雑でOK）
2. Claude が「区分 / 影響範囲 / リスク / 着手順」を整理して表に落とす
3. バッチ実行時に、リスクの低い順・依存の少ない順に上から消化 → 各項目 Roslyn 0err 確認

区別:
- **画像生成が必要なもの** → `docs/PENDING_IMAGEGEN_TASKS.md`（S4/S5陰影・F2〜F6融合・HUD素材）
- **ここ（このファイル）** → cs / ロジック / バランス / 挙動 / QoL / バグ など imagegen 不要の改善
