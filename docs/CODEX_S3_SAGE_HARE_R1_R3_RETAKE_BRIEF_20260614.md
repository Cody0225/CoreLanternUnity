## 補足ルール: 二足・半二足歩行について（2026-06-14 追記）

L3 retake では、**進化感・成熟感・戦闘力が出るなら二足歩行／半二足歩行になってもOK**。二足化そのものは NG ではない。
- **OK**: 「Sage Hare が進化した姿」に見える（長耳・ハレ顔/体型の名残・白/クリーム体毛＝種DNAが残る）。
- **NG**: 「別種族の人型キャラ」に見える／元種族DNAが消える／ただの人型ファイター／腕・拳だけで強さを表現／R1・R2・R3のルート文明差（発光色・素材・姿勢）が読めない／通常L3なのにULTIMATE級に豪華化。

## ① S3 Sage Hare / R1 SPEED / L3 — retake brief（サイバー文明）

狙い: 旧 `S3_R1_L3_RAW_VISUAL` は技術PASSだが、白/クリーム＋緑宝石＋古文様寄りで**サイバー文明としては弱い**。サイバー/青シアン/データライン/空力に寄せ直す。

必須:
- **青／シアン発光**を主役に（緑宝石主体をやめる）。
- **データライン**（回路/走査線的な発光ライン）を体・耳・脚に通す。
- **軽量装甲**（薄く絞ったプレート）＋**空力フィン**（流線エッジ）。
- **前傾・疾走・跳躍**の姿勢、細身・流線のシルエットで速さを表現。
- Sage Hare の**長耳・白/クリーム体毛は維持**（耳は空力的にスウェプトしてOK）。

減らす/禁止:
- 旧R1の**古文様・緑宝石寄りを減らす**（サイバー語彙へ置換）。
- 重金属装甲・炉心コア・橙発光（POWER寄り）禁止。
- 樹皮・蔦・苔（GUARD寄り）禁止。
- 巨大化・要塞・浮遊リング・魔法陣・粒子・スピード線・UI・文字・複数体・背景。

判定ポイント（生成後）:
- 一目で「青シアンの高速サイバー・ハレ」に見えるか。
- 速さが姿勢・細身・流線で出ているか（武器盛り/エフェクトに頼っていないか）。
- R2 POWER / R3 GUARD と発光色・素材で明確に差別化できるか。

## ② S3 Sage Hare / R3 GUARD / L3 — retake or review brief（樹皮と蔦の自然文明）

狙い: 旧 `S3_R3_L3_RAW_VISUAL` は低重心・守備感は良いが、**金属/石/古文様/宝石装甲に見えすぎる**場合がある。樹皮・蔦・葉・苔・根・木質装甲・自然甲殻に寄せ直す。

必須:
- **緑／ティール／翡翠発光**を主役に。
- **樹皮・蔦・葉・苔・根**を装甲・体表に取り入れる。
- **木質装甲・自然甲殻**（生体的・植物的な防御面）。
- **低重心・防御姿勢**（低く構えた安定スタンス）で守りを表現。
- Sage Hare の長耳・白/クリーム体毛は維持。

減らす/禁止:
- **金属板・鉱石装甲・鋼鉄プレート・炉心コア・橙発光は禁止寄り**（POWER語彙）。
- **石は主素材にしない**。使う場合は**苔むした自然石／土中の小さな岩片程度**の補助まで（岩塊・石壁化は不可）。
- 手持ち盾・エネルギーバリア・魔法陣リングで守りを表現しない。
- 青/シアン・データライン（SPEED寄り）禁止。
- 巨大化・要塞・浮遊リング・魔法陣・粒子・UI・文字・複数体・背景。

判定ポイント（生成後）:
- 一目で「樹皮と蔦の自然・防御ハレ」に見えるか。
- 守りが自然装甲＋低重心で出ているか（盾/鋼/石塊に頼っていないか）。
- POWER の金属/炉心語彙と混同していないか。
