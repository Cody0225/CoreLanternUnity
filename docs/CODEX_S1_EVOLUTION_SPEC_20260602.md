## 進化段階の原則（L0→L3）— 各段階を「新規フルボディ」で描く（最重要）

🔴 **各段階を、前段階のスプライトに盛り付けるのではなく、ゼロから新規に描く。**
過去に Codex 自身が出した「理想の進化3枚」（子狼 → 若い狼 → 威厳ある成獣）と
**同じ路線・同じ品質・同じ自由度**で。ポーズ・体格・シルエットを段階ごとに**大胆に**変える。

🔴 **やってはいけない（今回のWave1のNG例）**:
前段階の同じ座りポーズの子狼に、トゲ/羽/光エフェクトを足すだけ。これは進化ではない。

| 段階 | イメージ | ポーズ / 体格 |
|---|---|---|
| L0 | 素体の子狼 | 完成済み（見た目の系統＝青サイバー狼 だけ踏襲） |
| L1 | やんちゃな子狼＋装備の芽 | 子狼体型だが**新規作画**。素体の延長 |
| L2 | 若い狼（成長期） | **四足でしっかり立つ**。体格が一回り大きく、装甲・結晶が増える。ポーズも変える |
| L3 | 威厳ある成獣 | **大きく動的なポーズ**（踏み出す/咆哮/疾走感）。最終形の風格。画面を大きく使う |

- 守るのは「**青いサイバー狼の血統**」と「**SPEED の結晶/シアンのテーマ**」だけ。
  それ以外（ポーズ・構図・大きさ・シルエット）は段階で大胆に変えてよい・変えるべき。
- **同じポーズ・同じ枠・最小限の変化は禁止。**
- 段階で大きさと迫力が明確に増す。L3 は子狼の延長ではなく、堂々とした成獣。
- 512x512 内・透過・四隅 alpha=0 は維持。足元は概ね下側（接地感）でよいが、
  **占有高さは段階で増えてよい**（タイトル横並びの高さ統一ルールは進化形には適用しない。
  進化形は進化ツリー/ゲーム内用）。
- 3段階を横に並べ、**理想の3枚と同じくらい「格が上がっている」**か自分で確認。
  並べて違いが分からない/同じ子狼に見えるなら不合格、出さない。

## クロス融合（F1〜F6） = 4要素から2つの組合せ

🔴 **位置づけ: クロス進化はL4相当の「最強・究極フォーム」**（デジモンの超究極体のイメージ）。
ルートのL3最終形よりさらに上のティア。**神々しい / 圧倒的に強そう / とにかくかっこいい**こと。
- L3 ルート最終形より**明確に大きく・豪華で・格上**に見せる。
- 神々しさは**実体デザインで出す**: 豪華な究極装甲、大きく荘厳な翼、本体に組み込まれた
  光輪/王冠/結晶構造、体に刻まれた光るルーン/コア、金＋シグネチャ色の神聖なアクセント、
  王者の堂々としたポーズ。
- ただし**安っぽいゴミVFXは依然禁止**: バラけて浮く粒子/スパークル、動きの筋、
  平面的な照準リング/矢印、本体と無関係に散る装飾（＝前回の照準UI事故）。
  → 「光輪」は本体に溶け込んだ立体的な実体リングならOK。平面の線オーバーレイはNG。

4要素のビジュアル: **Nova**=放射状の閃光/スター（赤橙）, **Bulwark**=盾/装甲プレート,
**Siphon**=エネルギー吸引/データ粒子/連結, **Phase**=半透明の残像/ゴースト/流線。

| code | 融合名 | 構成 | アクセント色 | 見た目の合わせ方 |
|---|---|---|---|---|
| F1 | Nova Aegis | Nova + Bulwark | マゼンタ `#FF6BF5` | 閃光 + 盾。攻防一体の輝く装甲 |
| F2 | Photon Siphon | Nova + Siphon | ライム `#BDFF52` | 閃光 + 吸引。放射する集束データ |
| F3 | Core Bastion | Bulwark + Siphon | ゴールド `#FFDB57` | 盾 + 吸引。要塞的なコア防衛 |
| F4 | Nova Phantom | Nova + Phase | シアン `#61E5FF` | 閃光 + 残像。高速で光る幻影 |
| F5 | Aegis Drift | Bulwark + Phase | バイオレット `#C78FFF` | 盾 + 残像。機動する反射装甲 |
| F6 | Photon Wraith | Siphon + Phase | ティール `#6BFFC7` | 吸引 + 残像。粘る亡霊的データ体 |

融合は「青狼 + 2要素の融合」。種族の青はベースに残し、2要素の色/モチーフを乗せる。

## 統一仕様（全枚数で厳守）

- 512x512 / 接地点 `bottom_y = 448` / 四隅 alpha=0 / 透過PNG
- 本体ベタ部 alpha ≥ 230（透けスカスカ禁止）/ 内部に透け穴なし / 孤立ゴミ画素なし
- **陰影は新L0と同等のセルシェード（影・中間・ハイライト3階調＋濃い輪郭）。べた塗り厳禁。**
- 透過は透明キャンバスに直接描く。**chromakey の背景色抜きは使わない**（色飛びの原因）。
- 占有高さは段階で増えてよいが、512内・接地点448は固定。

🔴 **エフェクトの重ね掛け禁止（重要）**: キャラに「動きの筋/スピードライン/浮遊スパークル/
散る粒子/平面的な幾何リング・矢印/照準UI風オーバーレイ/余計なオーラ」を**焼き込まない**。
- 描くのは「キャラ本体＋実体のある装甲・武器・パーツ・コアジェムの発光」だけ。
- 残像・グロウ・パーティクル・動きの演出は**後で Claude がコードで足す（Type A）**ので、
  静止画には入れない。スプライトはクリーンに保つ。
- ルートのテーマは「実体（結晶の翼・砲・盾板など）」と「キャラ自身の発光」で表現し、
  飛び散る装飾エフェクトでごまかさない。
