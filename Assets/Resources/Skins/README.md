# Optional Local Skins

Put your own private PNG sprites in this folder. The game can load them as `Texture2D` and create sprites at runtime, so Unity's Sprite Mode can stay on the default importer setting during prototyping.

Supported names:

- `Player.png`
- `Player_Form1.png`
- `Player_Form2.png`
- `Player_Form3.png`
- `Player_Form4.png`
- `Lantern.png`
- `Runner.png`
- `Brute.png`
- `Shooter.png`
- `Boss.png`
- `Link_Nova.png`, `Link_Bulwark.png`, `Link_Siphon.png`, `Link_Phase.png`
- `Partner_S1_L0.png` ... `Partner_S6_L0.png`
- `Partner_S{species}_R{route}_L{stage}.png`
- `Route_1_Stage0.png` ... `Route_3_Stage3.png`
- `Partner_S{species}_F{fusion}_L{stage}.png`
- `Fusion_1.png` ... `Fusion_6.png`
- `Floor_TileA.png`, `Floor_TileB.png`, `Floor_TileC.png`
- `Card_Cyan.png`, `Card_Gold.png`, `Card_Green.png`, `Card_Magenta.png`, `Card_Red.png`
- `Bullet_Speed.png`, `Bullet_Power.png`, `Bullet_Guard.png`, `Bullet_Fusion.png`
- `Pickup_Data.png`, `Evolution_Ring.png`

After importing, stop Play mode and press Play again.

These files are for your local project only. Do not publish or distribute copyrighted character artwork unless you have permission.

For a safe shareable version, use original digital-monster-style designs instead of official characters.
