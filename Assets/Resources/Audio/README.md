# Optional Audio

Put original or commercially usable audio files in this folder.

Supported names:

- `BGM.wav`
- `Shoot.wav`
- `Hit.wav`
- `Kill.wav`
- `Pickup.wav`
- `LevelUp.wav`
- `Evolve.wav`
- `Fusion.wav`
- `Boss.wav`
- `GameOver.wav`

Unity also accepts common formats such as `.mp3` and `.ogg`, but `.wav` is easiest for short sound effects.

If a file is missing, the game falls back to simple generated electronic tones.
